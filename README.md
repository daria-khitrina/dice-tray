# Dice Tray

A 3D dice roller for tabletop games — d4, d6, d8, d10, d12, d20, d100 — rendered with [Three.js](https://threejs.org/). Dice sit on a tilted ring: swipe left/right to pick one, swipe up/down to roll. Long-press (or use the gear button) to choose which dice are shown.

Live at [dice.dariakhitrina.com](https://dice.dariakhitrina.com).

Single self-contained `index.html`, no build step.
